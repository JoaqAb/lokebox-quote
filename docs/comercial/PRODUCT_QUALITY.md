# Calidad de producto · Lokebox Quote

Fecha: 2026-09-11

## Objetivo

Lokebox Quote no debe sentirse como una demo técnica correcta. Debe percibirse como un producto premium que una empresa pueda imaginar con su propia marca y quiera mostrar a sus clientes.

La base técnica y de arquitectura se considera separada de esta auditoría. El foco de esta capa es percepción, claridad, deseo, confianza y calidad visual.

## Regla de ejecución

No se retrasa el cierre funcional para perseguir estética. Primero se completa el flujo vendible. Después se hace una auditoría específica de producto/visual y se corrigen únicamente los puntos que impidan alcanzar sensación premium.

## Quality gate comercial

Antes de considerar V1 lista para vender fuerte, la demo debe pasar:

1. Test de 10 segundos: sin explicación, una persona entiende qué configura y qué obtiene.
2. Screenshot test: una captura puede usarse en portada de Upwork, landing o outreach sin necesidad de justificarla.
3. Interaction test: cambios de tamaño, material e iluminación producen efectos visuales claros y satisfactorios.
4. Brand test: cambiar logo, colores y textos hace que parezca realmente producto del cliente, no Lokebox disfrazado.
5. Trust test: precio/estimación, formulario, WhatsApp y quote final se sienten como un flujo comercial terminado.
6. Mobile test: la experiencia conserva calidad percibida, claridad y control en teléfono real.

## Dirección visual

Hipótesis a evaluar en la auditoría final:
- interfaz general más clara y luminosa puede funcionar mejor para este producto que una UI predominantemente oscura;
- fondo claro/nocturno debe decidirse por contraste y protagonismo del producto 3D, no por preferencia estética aislada;
- priorizar mucho aire, tipografía limpia, jerarquía fuerte y controles discretos;
- el producto configurado debe dominar visualmente la escena;
- iluminación/materiales deben sentirse físicos y no como efectos de demo;
- transiciones deben comunicar calidad, no llamar la atención sobre sí mismas;
- evitar cualquier detalle que huela a prototipo o panel técnico.

## Upgrade WOW condicionado al tiempo

Si el MVP funcional está cerrado con margen, la primera mejora visual reusable será soporte convincente para letras corpóreas / channel letters.

Motivos:
- coincide con los productos de mayor interés detectados en prospectos locales;
- mejora mucho la fuerza de la hero shot;
- sirve también para mercado internacional;
- no debe implementarse como parche para un cliente concreto, sino como capacidad reusable de la vertical signage.

Condición: no puede retrasar la salida comercial.

## Auditoría posterior a Code

Cuando Code cierre el alcance funcional, hacer un pase separado llamado VISUAL / PRODUCT QUALITY PASS sobre:
- desktop 1440;
- tablet;
- mobile real;
- estados de iluminación;
- materiales;
- branding;
- formulario;
- WhatsApp;
- quote final;
- capturas de venta;
- sensación general de producto premium.

Resultado por ítem: PASS / NO PASS / corrección requerida.

No reabrir arquitectura ni sumar features salvo que una carencia visual/comercial sea claramente bloqueante para vender.
