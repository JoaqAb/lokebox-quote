# Oferta local · Lokebox Quote

Fecha: 2026-09-12
Estado: V1 cerrada para primeros clientes de Tucumán

## Objetivo

Vender Lokebox Quote como una implementación productizada, de alcance cerrado y rápida puesta en marcha. El cliente compra un resultado concreto; no compra horas de desarrollo ni un proyecto abierto.

## Founding Tucumán

Precio de referencia para los primeros 2–3 clientes locales:

- Setup: USD 250 equivalente en ARS
- Lokebox Quote Platform: USD 39/mes equivalente en ARS
- Alcance: Starter local
- Una familia de producto
- Una ronda de revisión

El precio externo debe presentarse como una cifra única. USD 200 de setup queda únicamente como excepción privada para un caso estratégico y no como tarifa publicada.

## Qué recibe el cliente

### 1. Experiencia Quote con su marca

- logo del negocio;
- colores y textos básicos de marca;
- URL propia dentro de Lokebox Quote: `quote.lokebox.com/d/<slug>`;
- experiencia responsive para desktop y mobile;
- sin necesidad de rehacer su sitio actual.

### 2. Una familia de producto

Se configura una única familia comercial reutilizando las capacidades existentes de la vertical signage.

Ejemplos:
- letras corpóreas;
- cartel de fachada;
- tótem;
- otra familia que encaje razonablemente en los módulos existentes.

La familia puede utilizar variables estándar soportadas por Quote, por ejemplo:
- medidas;
- material;
- iluminación;
- cantidad;
- instalación cuando corresponda;
- otras opciones estándar ya disponibles en el core.

No implica desarrollar un nuevo configurador desde cero.

### 3. Visualización interactiva

- preview visual / 3D basado en los componentes existentes de Quote;
- cambios visibles según las opciones configuradas;
- materiales/iluminación existentes que correspondan al producto;
- calidad final sujeta al Product Quality Pass de Lokebox antes de la salida comercial.

### 4. Pricing / estimación

Incluye un esquema estándar de pricing, rango o precio orientativo basado en reglas que puedan expresarse con el motor existente.

El negocio puede elegir, según el caso:
- precio estimado;
- rango;
- precio “desde”;
- ocultar precio final y usar Quote solo para estructurar la solicitud.

El cliente debe proveer su lista de precios/reglas y validar los resultados.

No incluye diseñar desde cero un sistema complejo de costos internos.

### 5. Captura de consulta

- formulario y/o WhatsApp según configuración;
- datos del cliente;
- configuración seleccionada;
- resumen estructurado de la solicitud;
- almacenamiento del lead dentro de la infraestructura de Quote cuando corresponda.

No incluye CRM, pipeline comercial ni backoffice de gestión.

### 6. Quote / resumen

- resumen de configuración;
- versión imprimible según las capacidades del core;
- branding básico del negocio.

No se promete una factura, orden de venta o documento fiscal.

### 7. Implementación

Incluye:
- una instancia de onboarding / relevamiento corto;
- carga inicial de logo, colores, textos, opciones y reglas de pricing;
- configuración de contacto/WhatsApp;
- QA;
- publicación;
- una ronda consolidada de correcciones dentro del alcance.

Objetivo comercial de entrega: 3–5 días hábiles desde que Lokebox recibe todos los insumos completos y el alcance está cerrado.

## Qué debe entregar el cliente

Para iniciar:
- logo en buena calidad;
- colores/identidad si existen;
- nombre y datos de contacto;
- WhatsApp/contacto destino;
- familia de producto elegida;
- opciones que quiere ofrecer;
- materiales/acabados;
- reglas de precio o lista de precios;
- textos comerciales básicos;
- imágenes/referencias del producto cuando sean necesarias.

Si la información llega incompleta, contradictoria o requiere rediseñar el proceso comercial antes de poder configurarlo, el plazo se pausa hasta resolverlo.

## Qué NO incluye el setup de USD 250

No incluye:
- más de una familia de producto;
- modelado 3D bespoke complejo desde cero;
- creación de assets 3D altamente específicos para un solo cliente;
- rediseño de la web actual del cliente;
- implementación dentro del código de su sitio;
- e-commerce o checkout/pagos online;
- CRM o dashboard/backoffice;
- usuarios, login o permisos;
- ERP, sistema contable o integraciones complejas;
- workflows internos a medida;
- automatizaciones comerciales fuera del flujo estándar de Quote;
- IA custom;
- Photo-to-Sign salvo que se venda expresamente como add-on;
- diseño desde cero de su sistema de costos o pricing;
- carga masiva de catálogos;
- múltiples monedas o lógicas comerciales complejas;
- revisiones ilimitadas;
- cambios de alcance una vez aprobado el onboarding.

Todo lo anterior se cotiza como add-on, Pro, Custom o implementación de Lokebox Platform según el caso.

## Qué cubre la mensualidad de USD 39

La mensualidad se presenta como Lokebox Quote Platform, no como simple hosting.

Incluye:
- hosting y operación de la instancia;
- mantenimiento del core;
- actualizaciones generales de Quote;
- monitoreo básico;
- corrección de bugs del producto;
- soporte razonable;
- almacenamiento/operación del flujo estándar de leads;
- hasta una solicitud agrupada de cambios menores de configuración por mes, por ejemplo texto, contacto o ajuste puntual de un valor existente.

No incluye en la mensualidad:
- nuevas familias de producto;
- nuevas reglas complejas de pricing;
- rediseños visuales;
- nuevas integraciones;
- features exclusivas para el cliente;
- cambios que requieran desarrollo específico.

## Revisión y cambios

El setup incluye una ronda consolidada de revisión antes del go-live.

Una ronda significa que el cliente reúne sus observaciones y las entrega juntas. Correcciones de errores de Lokebox no consumen esa ronda.

Cambios de criterio o alcance después de aprobar la configuración inicial se cotizan aparte si exceden cambios menores.

## Forma comercial recomendada

No presentar una lista técnica extensa en el primer contacto.

Secuencia:
1. mostrar el resultado;
2. validar interés;
3. explicar que es una implementación cerrada para una familia de producto;
4. presentar setup + mensualidad;
5. enviar el alcance resumido;
6. hacer onboarding solo después del sí comercial.

## Política de pago sugerida para founding local

- 50% del setup para iniciar;
- 50% del setup al aprobar/publicar;
- mensualidad comienza con el go-live;
- cobro en ARS equivalente según la referencia definida en la propuesta vigente.

La propuesta en ARS debe tener una validez limitada para evitar descalce por variación cambiaria.

## Regla central

> El precio founding compra una implementación de Lokebox Quote. No compra desarrollo ilimitado.

Si una necesidad no puede resolverse principalmente mediante configuración del core existente y capacidades reutilizables, queda fuera de este paquete.
