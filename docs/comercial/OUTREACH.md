# Outreach directo · Lokebox Quote

Fecha: 2026-09-11
Estado: V1 operativa

## Principio

No depender del Instagram de Lokebox para vender. Instagram y WhatsApp son canales de entrada; la credibilidad debe venir del producto y de un kit comercial mínimo, visual y autónomo.

No invertir ahora en estrategia de contenido, calendario, crecimiento orgánico ni feed elaborado. Eso se delega cuando haya ingresos.

## Kit mínimo para contacto directo

### 1. Mensaje inicial corto

Objetivo: conseguir atención, no explicar todo el producto.

Debe:
- demostrar que vimos el negocio;
- mencionar un problema concreto del prospecto;
- presentar una sola idea;
- invitar a ver algo visual;
- evitar presentación corporativa larga.

### 2. Pieza WOW inmediata

Prioridad:
- video/GIF de 10–20 segundos mostrando transformación del configurador;
- alternativa: before/after Photo-to-Sign;
- alternativa: captura premium si el canal no permite video cómodamente.

Debe mostrar antes de explicar:
- cambio de material/iluminación/tamaño;
- efecto visual claro;
- precio/estimación reaccionando;
- si existe, corpóreas/channel letters como hero.

### 3. Demo pública

URL de Lokebox Quote lista para abrir en mobile sin login.

Objetivo: que el prospecto pueda probarlo solo.

No enviar al home general de Lokebox cuando el interés es Quote. Enviar al demo o landing específica de Quote.

### 4. Landing corta de producto

Debe resolver en una pantalla inicial:
- qué es;
- para quién sirve;
- qué problema resuelve;
- demo;
- cómo funciona;
- llamada a acción.

No convertirla en una web corporativa grande.

### 5. One-pager solo cuando haya interés

PDF/hoja de una página, no como primer contacto.

Contenido:
- problema;
- flujo configure → visualize → estimate → quote;
- qué incluye la implementación;
- tiempo estimado de entrega;
- precio/founding offer cuando corresponda;
- mensualidad/plataforma;
- contacto Joaquín / Lokebox.

### 6. Demo personalizada para leads A

Solo para prospectos con alto fit.

Posibles personalizaciones rápidas:
- nombre/logo del prospecto;
- colores;
- producto similar al que venden;
- Photo-to-Sign de una fachada de ejemplo propia o autorizada;
- una configuración que represente una línea real de su catálogo.

No hacer implementaciones gratis.

## Secuencia recomendada

Contacto frío → pieza WOW → demo → conversación corta → discovery → propuesta/founding offer → setup → entrega.

No enviar de entrada: mensaje largo + PDF + precios + video + web + calendario. Reducir fricción.

## Rol de Instagram

Instagram de Lokebox funciona inicialmente como verificación de existencia, no como motor de adquisición.

Mínimo aceptable antes del outreach:
- logo correcto;
- bio clara;
- link correcto;
- 3 piezas razonables/publicadas;
- sin información contradictoria o desactualizada.

No hace falta:
- publicar todos los días;
- llenar 9/12 posts antes de contactar;
- producir reels en volumen;
- construir audiencia primero.

Cuando Quote esté terminado, priorizar hasta 3 piezas fijas/pinneadas si resulta fácil:
1. qué hace Lokebox;
2. Lokebox Quote / configurador visual;
3. caso/flujo de automatización.

## Identidad en contacto

Venta founder-led:
- Joaquín es quien escribe y conversa;
- Lokebox es la empresa;
- Lokebox Quote es el producto.

No ocultar al fundador detrás de una voz corporativa artificial.

## Material por canal

### WhatsApp

Prioridad: texto corto + video/GIF o captura + link a demo.

### Instagram DM

Prioridad: texto todavía más corto. Si responde, pasar demo/video. No depender de que revise el feed completo.

### Email

Puede incluir demo + una imagen/GIF y una explicación ligeramente mayor, pero mantener foco visual.

## Regla comercial

El primer activo debe provocar: “quiero ver eso”.
El segundo debe provocar: “esto podría servir para mi negocio”.
La conversación recién después explica alcance, precios e implementación.
